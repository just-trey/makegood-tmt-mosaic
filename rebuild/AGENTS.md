# Start with PROMPT.md

This repository holds a brief and reference files, nothing else yet. Read `PROMPT.md` in full,
then `EVAL.md`, then build the tool the brief describes, in this repository, at the root.

- Keep decisions, open questions and known limitations in `NOTES.md` as you go.
- Commit as you work. Small commits with messages that say what changed.
- Use the files under `reference/`. Looking up file formats and standards is fine. Do not look
  for an existing tool that does this job and copy it.
- If something in the brief is ambiguous, pick the reading that best serves the volunteer
  described in it, and write the choice down in `NOTES.md`. Do not stop to ask.
